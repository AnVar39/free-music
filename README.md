# Свободная музыка (PWA)

Поиск легально бесплатной музыки на Internet Archive.

## Публикация на GitHub Pages
1. Создайте репозиторий на github.com (например, `free-music`), загрузите все файлы из этой папки в корень.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу https://ВАШ_ЛОГИН.github.io/free-music/

## Установка
- Android (Chrome): меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран Домой».
- Компьютер (Chrome/Edge): значок установки в адресной строке.
