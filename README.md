# Свободная музыка

Поиск легально бесплатной музыки (Creative Commons и общественное достояние) на Internet Archive.
Работает как сайт, как установленное приложение (PWA) и как APK для Android.

## 1. Загрузите файлы в GitHub
1. Создайте репозиторий на github.com (например, `free-music`).
2. **Распакуйте архив** и загрузите его *содержимое* в корень репозитория
   («Add file» → «Upload files»; перетащите файлы и папки, а не сам zip и не папку-обёртку).
   `index.html` должен лежать в корне.
3. Если папка `.github` не загрузилась (скрытые папки часто теряются): «Add file» → «Create new file»,
   в имя файла введите `.github/workflows/build-apk.yml` и вставьте содержимое из `build-apk.yml.txt`.

## 2. APK (сборка автоматическая)
После загрузки в ветку `main` сборка запустится сама (вкладка **Actions**, 5–10 минут).
Готовый файл `free-music.apk` — справа на главной странице репозитория, раздел **Releases**.
Откройте ссылку на телефоне, скачайте APK и разрешите установку из этого источника.
Ручной запуск: Actions → «Сборка APK» → Run workflow.

APK подписан отладочным ключом: для личного использования подходит, в Google Play с ним публиковать нельзя.
Нужен Android 10 и новее. Скачанные треки сохраняются в папку «Музыка/FreeMusic».

## 3. Сайт и установка ярлыком
Settings → Pages → Deploy from a branch → `main` / `(root)`. Через минуту сайт будет на
`https://ВАШ_ЛОГИН.github.io/free-music/`. В Chrome откройте его и нажмите «Установить приложение»
(на iPhone: Safari → «Поделиться» → «На экран Домой»).
